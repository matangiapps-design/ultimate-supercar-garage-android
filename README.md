# Ultimate Supercar Garage - Android

WebView-based Android app loading the interactive 3D supercar showroom.

## Features
- 200+ car catalog with hybrid specs
- Three.js 3D viewer with drive controls (WASD)
- Paint customization
- Brand filtering

## Build
1. Open in Android Studio
2. Sync Gradle
3. Run on device or emulator

Package: com.manassupercar.garage
